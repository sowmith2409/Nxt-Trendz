# 🛍️ Nxt Trendz – Online Shopping Application (Frontend)

**Tech Stack:** React.js | JavaScript | HTML | CSS | React Router | Context API | Cookies  
**Duration:** 1 Week  

## 📖 Project Overview
Developed the **frontend** of *Nxt Trendz*, an online shopping application inspired by Amazon, focused on providing an intuitive and responsive user experience. The application allows users to **log in, search, filter, sort, and add products to the shopping cart**.

## 🚀 Features
- 🔐 **Authentication Flow** – Implemented login validation with error handling for invalid credentials and used cookies to persist sessions.  
- 🛒 **State Management** – Utilized **Context API** to manage global cart state across routes.  
- 🌐 **Routing & Navigation** – Used **React Router** for page transitions and implemented **protected routes** for access control.  
- 📦 **Mock API Integration** – Connected mock APIs to simulate real-world product and cart functionalities.  
- 🧩 **Clean Code Practices** – Maintained reusable components, consistent folder structure, and meaningful naming conventions.  
- 📱 **Responsive Design** – Used **media queries** and **flexbox** to ensure adaptability across all devices.

## 🎯 Learning Outcomes
- Strengthened skills in **React authentication**, **state management**, and **routing**.  
- Improved understanding of **frontend architecture** and **responsive web design** principles.
